Original Artifact Analysis

The original artifact was a Python-based dashboard application developed during CS-340. The application connected to MongoDB and provided an interactive interface for viewing and filtering animal rescue data.

The code review identified several areas where the application could be improved:

  • Improved separation between frontend, backend, and database responsibilities.
  • Additional security through authentication and authorization.
  • Improved scalability through optimized data access strategies.
  • Expanded automated testing coverage.
  • Improved maintainability through modern software architecture.

Planned Enhancement Areas

Software Design & Engineering

The application architecture was redesigned using the MEAN stack with an Angular frontend, Express REST API, Node.js backend, authentication, authorization, and improved testing practices.
