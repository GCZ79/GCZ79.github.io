CS-499 Capstone Project

This ePortfolio showcases my enhanced CS-499 Capstone Project, based on the Grazioso Salvare Animal Rescue Dashboard originally developed during CS-340: Client/Server Development.

The original application was transformed into a modern full-stack web application using the MEAN stack. The enhanced project demonstrates improvements in software engineering practices, algorithm efficiency, and database design.

Technical Skills Demonstrated

Software Design & Engineering

Implemented a full-stack migration using Angular, TypeScript, Node.js, and Express. Added authentication, authorization, route protection, REST API improvements, and automated testing.

Algorithms & Data Structures

Improved application performance through MongoDB indexing, aggregation pipelines, server-side pagination, and an LRU cache implementation for frequently accessed data.

Database Design

Enhanced MongoDB functionality through improved validation, data management strategies, optimization techniques, and scalable database practices.
